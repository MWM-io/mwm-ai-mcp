# Security reporting

For a suspected vulnerability, exposed credential, or account-access issue,
contact [support@mwm.ai](mailto:support@mwm.ai) privately. Include the affected
client and version, installation method, relevant time, and a minimal
reproduction with sensitive data removed.

Do not post tokens, passwords, store credentials, private account data, or
exploitation details in a public issue. Public issues are appropriate for
documentation and packaging bugs that do not disclose sensitive information.

This repository distributes plugin instructions and connection metadata.
MWM's hosted MCP service is deployed separately. The package contains no
account credentials; each user authorizes their own MWM connection.

See the [privacy policy](https://console.mwm.ai/mcp/privacy) and
[terms](https://mwm.ai/terms-of-service) for the hosted service.
